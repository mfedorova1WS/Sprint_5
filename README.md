# Проект автоматизации тестирования конструктора бургеров "stellarburgers"
1. Инструменты и технологии
- Python
- Pytest
- Selenium (для автоматизации тестирования через браузер)
2. Установить зависимости — pip install -r requirements.txt.
3. Команда для запуска — pytest -v.
4. Необходима установка пакета webdriver_manager
